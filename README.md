## 📂 Repository Structure

Each topic contains:

```
Basics/
Easy/
Medium/
Hard/
README.md
```

For **Arrays**, problems are organized by patterns instead of difficulty.

```
Arrays/
│── Basics/
│── TwoPointers/
│── Hashing/
│── PrefixSum/
│── SlidingWindow/
│   ├── FixedSize/
│   └── DynamicSize/
│── KadanesAlgorithm/
│── Matrix/
│── README.md
```

For **Strings**, problems are organized as:

```
Strings/
│── Basics/
│── README.md
```

Files inside every folder:

```
problem-name.cpp
README.md
```
